# typescript-codegen-test

Hand-written codegen sources that emit ~400 generated TS files (>40k LOC).
Fixture for the sonar-review split-review fan-out **Haiku pre-filter** —
exercises the case where a PR contains a tiny number of source-of-truth
files plus a large amount of auto-generated content.

## Layout

Hand-written sources (8 files):

- `codegen/entities.yaml` — declarative schema, 65 entities × ~7 fields each
- `codegen/generate.py` — Python generator that reads the YAML and the templates
- `codegen/templates/model.tmpl`
- `codegen/templates/repository.tmpl`
- `codegen/templates/service.tmpl`
- `codegen/templates/controller.tmpl`
- `codegen/templates/validator.tmpl`
- `codegen/templates/entity_index.tmpl`
- `codegen/templates/test.tmpl`

Generated outputs (do not edit):

- `src/generated/<slug>/{model,repository,service,controller,validator,index}.ts`
- `src/generated/index.ts` (aggregator)
- `tests/generated/<slug>.test.ts`

Every generated file starts with an `AUTOGENERATED from …` banner so reviewers
and the split-review pre-filter can identify them at a glance.

## Regenerate

```sh
python3 codegen/generate.py
```
